# Версии шаблона — теги PEP 440

Статус: accepted (восстановлено по истории)

`copier update` переводит проект с тега генерации на новейший. Copier молча игнорирует теги не по PEP 440 (`v1.1.0-test`) и сообщает «нечего обновлять», поэтому релиз шаблона — аннотированный тег `vX.Y.Z` (допустим `v1.2.0rc1`). Версия самого пакета берётся из git-тегов, не из файла.
