## Problem

`sh scripts/check_template.sh` on main (5e08545) is red at the all-parts variant:

```
error[missing-attribute]: Object of type `Command` has no attribute `commands`
  --> tests/test_skills.py:23:19
23 |     return sorted(typer.main.get_command(app).commands)
```

CG-091 removed the `assert isinstance(root, typer.core.TyperGroup)` line that used to narrow the type (it kept the `typer.core` name out of the template). `get_command` is typed to return a bare `Command`; only at runtime is it a group with `.commands`.

## Fix

Bring the narrowing back without `typer.core`:

```python
def _commands() -> list[str]:
    root = typer.main.get_command(app)
    assert isinstance(root, typer.main.TyperGroup)  # get_command is typed Command; the root is a group
    return sorted(root.commands)
```

`typer.main.TyperGroup` exists in 0.27.3, 0.28.0 and 0.29.1 (checked), and `typer.main` is already imported for `get_command`. Any equivalent narrowing that keeps `typer.core` out of the template tests and satisfies ty is fine — this one is the smallest.

Verify with `sh scripts/check_template.sh` (background, ~6 min): the all-parts variant's `ty check` step must print `All checks passed!`.
