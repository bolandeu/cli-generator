# Таблицы БД: один PRIMARY KEY из одной колонки, кэш в схеме cache

Статус: accepted (восстановлено по истории)

Каждая таблица слоя БД (`include_db`) имеет первичный ключ из одной колонки: Directus не поддерживает составные ключи (v1.4.6). Таблицы вида `kind="cache"` живут в схеме PostgreSQL `cache` (v1.6.0). Эти решения трудно отменить — на них уже лежат данные и потребители.
