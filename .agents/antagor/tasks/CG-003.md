Сгенерированный проект не приносит свои хуки и больше не знает towncrier. Хуки: нет .githooks/, scripts/install_hooks.sh, .claude/settings.json (SessionStart с core.hooksPath и herdr_name, PostToolUse/Stop на check_command_docstrings); сама check_command_docstrings.py остаётся — её вызывает checks проекта; тесты не ссылаются на удалённое (образец: git -C ~/Work/tools/sitemap-xml show 9b1924c --stat). Towncrier: нет зависимости, [tool.towncrier], changelog.d/, шага гейта «changelog fragment», команд patch|minor|major, check_changelog_fragment.py и release_commit. release.py умеет только --check (остальные шаги гейта и коды выхода 1/3 без изменений); версия остаётся в git-тегах (uv-dynamic-versioning). CHANGELOG.md шаблона — шапка без маркера towncrier (changelog пишет antagor publish). Образец: git -C ~/Work/tools/sitemap-xml log -p 4adbc69..main -- scripts/release.py pyproject.toml tests/test_scripts.py CHANGELOG.md.
