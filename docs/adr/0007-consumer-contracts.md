# Контракты потребителей прогоняются отдельным шагом гейта

Статус: accepted (восстановлено по истории)

Потребитель CLI (например, windmill → serp) кладёт YAML-контракт `contract: 1` в `tests/contracts/<потребитель>/`; гейт прогоняет его своим шагом (v1.7.0). Формат — формат потребителей, принимается как есть (v1.8.0–v1.8.1): раннер подстраивается под их файл, а не наоборот. Реальный контракт хранится дословной копией в `tests/data/contracts/`.
