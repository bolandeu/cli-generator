The antagor step of this repo's template-gate workflow runs `antagor --version` after the install. antagor has no `--version` option, so the step exits 2 and every CI run fails before the template gate. Remove that one line; keep the install line and its pin as they are. Nothing else changes.

## Out of scope

- The Python version of the workflow, the antagor pin, the template's own CI workflow, the gate.
