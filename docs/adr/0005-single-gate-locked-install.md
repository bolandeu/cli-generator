# Один локальный гейт, установка колеса только из locked-зависимостей

Статус: accepted (восстановлено по истории)

Проверка перед релизом сгенерированного проекта — `scripts/release.py --check`; CI необязателен и лишь запускает её. Шаг «собрать и установить колесо» ставит только locked-набор зависимостей: обычный `uv pip install <колесо>` взял бы с PyPI одноимённый чужой пакет (dependency confusion, v1.2.3), шаг падает, если пакет пришёл из индекса вместо git-источника.
