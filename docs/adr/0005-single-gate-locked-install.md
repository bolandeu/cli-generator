# Один локальный гейт, установка колеса только из locked-зависимостей

Статус: accepted (восстановлено по истории; обновлено после CG-027: набор ставит `uv sync --frozen`, наши пакеты привязаны к явному индексу). В части CI заменено 0015.

Проверка перед релизом сгенерированного проекта — `scripts/release.py --check`; CI необязателен (Gitea Actions, `.gitea/workflows/ci.yml`) и лишь запускает её. Шаг «собрать и установить колесо» ставит ровно locked-набор зависимостей: `uv sync --frozen --no-dev --no-install-project` в чистое окружение, затем колесо с `--no-deps` и `uv pip check`. Обычный `uv pip install <колесо>` не видит `[tool.uv.sources]` и взял бы с PyPI одноимённый чужой пакет (dependency confusion, v1.2.3).

Наши пакеты берутся из реестра Gitea через явный индекс (`[[tool.uv.index]] name = "gitea"`, `explicit = true`; в зависимостях `rb-x>=…`, в `[tool.uv.sources]` `rb-x = { index = "gitea" }`), а не из git-тега. Шаг падает, если пакет из `[tool.uv.sources]` с явным индексом установлен не той версии, что записана в `uv.lock` (пришёл из другого индекса, например PyPI).
