Gitea Actions sets GITHUB_ACTIONS=true. Typer reads it (and FORCE_COLOR, PY_COLORS) at import and forces Rich terminal output with ANSI codes. A test that passes on the Mac then fails in CI: today the template's own test of a usage error without --json fails in every CI run of the template gate and of every new package, while the gate on the Mac is green.

Two changes:
1. The template's tests pass under the CI variables. The usage-error test checks the option name in the error text whatever the colour; any other test that breaks under the CI variables is fixed the same way. Tests are not deleted or weakened.
2. The gate's pytest step runs with GITHUB_ACTIONS=true, FORCE_COLOR=1 and PY_COLORS=1 added to its environment, so a package that would fail in CI fails the gate on the Mac first, with the same failing test. The template gate script runs the rendered packages' pytest the same way.

## Acceptance

- Given a package rendered from the template (minimal and all parts), When its tests run with GITHUB_ACTIONS=true FORCE_COLOR=1 PY_COLORS=1, Then all pass, including the usage-error test without --json [check: sh scripts/check_template.sh]
- Given a package with a test that passes without the CI variables and fails with GITHUB_ACTIONS=true, When rb-release check runs on the Mac with no such variable set, Then the pytest step fails and names that test [check: gate/tests/test_release.py]
- Given a package whose tests pass under the CI variables, When rb-release check runs, Then the pytest step passes as before [check: gate/tests/test_release.py]

## How to test

Gate: an integration test in the gate's test file over a tiny package fixture whose test asserts that GITHUB_ACTIONS is unset (red under the gate, green under plain pytest). Template: the template gate script renders the variants and runs their suites under the CI variables.

## Basis

The template's tests conftest already has CI_ENV and the same_in_ci fixture: reuse that set of variables; the gate defines the same three. Keep the gate's step names and output lines unchanged.
