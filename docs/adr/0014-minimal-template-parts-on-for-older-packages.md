# Минимальный шаблон: необязательная часть выключена в новом пакете и включена у старого

Статус: accepted (Человек, 2026-10-20, план `docs/plans/simple-standard.md`; CG-047)

Пакет с ответами по умолчанию содержит только обязательное по Стандарту; проект, ключи, провайдеры, база, скилл
пакета, `describe` и контракты с detach — вопросы copier. Новый вопрос по умолчанию «нет» при `copier copy` и «да» при
`copier update`, иначе старый пакет потерял бы часть: общий код (`cli.py`, `doctor`) регистрирует часть, только когда
её модуль есть. Copier 9.19 не даёт `_copier_operation` в default вопроса, поэтому признак update — скрытая переменная
`updating`: прежний `.copier-answers.yml`, прочитанный через `_external_data`, есть только при update (при copy copier
пишет `MissingFileWarning`). Команда `docs` и её OpenCLI-документ ушли из шаблона (заменяет 0008: `clidocs` рисует из
`describe --json`); вопрос `include_ci` ушёл — CI обязателен (шаг гейта `standard: ci`).
