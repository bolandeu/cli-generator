Row F4.9 of the CG-082 extraction: check_command_docstrings.py dumps node.args whole and compares it with the docstring, so adding typer.Context to a command signature reads as a changed logic and a correct docstring fails.

Fix: drop a ctx-only argument from the compared signature (and the return annotation case, if present), keep every other comparison as it is. Add the two-case unit test above; the second case is the guard that the checker still catches a real change.

## Acceptance

- Given a command whose signature gains only ctx, when check_command_docstrings.py runs, then it passes and the docstring is untouched [check: sh scripts/check_template.sh]
- Given a command whose real arguments change, when the checker runs, then it still fails as before [check: sh scripts/check_template.sh]

## How to test

Unit test on the checker with two canned command ASTs: one whose only change is ctx, one whose argument list really changed; plus the template gate.
