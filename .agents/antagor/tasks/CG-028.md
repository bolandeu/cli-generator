The template gate also proves a copier update round: a project generated from the previous release tag is updated to the working tree with copier update --trust --defaults, with no keys in env or keychain and no prompts, and the full gate passes after it. A new script in this repo reports, for every repo of the Gitea org bolandeu, the template version in its .copier-answers.yml and whether it lags behind the latest template tag; --json gives the same as data. The repo's own tests for this script run inside the template gate.

## Acceptance

- Given the previous template tag and the working tree, When check_template.sh runs, Then it generates from the tag, runs copier update --trust --defaults with stdin closed and no credential env vars, and the gate passes in the updated project [check: sh scripts/check_template.sh]
- Given a faked Gitea API with repos a (answers _commit v1.20.0), b (v1.18.2) and c (no answers file) and latest tag v1.20.0, When template_drift.py --json runs, Then a is current, b lags by version, c is listed as not from the template [check: tests/test_template_drift.py]
- Given the same data, When template_drift.py runs without --json, Then it prints one line per repo with name, version and status, lagging ones first [check: tests/test_template_drift.py]
- Given Gitea is unreachable or returns 5xx, When template_drift.py runs, Then it prints a named error with the URL and exits non-zero, with no partial table [check: tests/test_template_drift.py]
- Given check_template.sh, When it runs, Then it runs the repo tests under tests/ and fails if they fail [check: sh scripts/check_template.sh]

## How to test

Unit: tests/test_template_drift.py with the HTTP layer faked (no network). Integration: check_template.sh with the update round. The script is a single file with PEP 723 inline deps runnable by uv run; tests run with uv run --with pytest.

## Basis

Gitea API: GET /api/v1/orgs/bolandeu/repos (paged), raw file .copier-answers.yml per repo, tags of bolandeu/cli-generator; base URL https://homeserver.tailee01ab.ts.net:3000, anonymous read. Pick versions with packaging.version (PEP 440) like copier does.
