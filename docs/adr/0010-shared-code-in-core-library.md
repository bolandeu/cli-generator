# Общий код пакетов — в библиотеке-ядре, не в копиях шаблона

Статус: accepted (Человек, 2026-10-19; IDEA-254)

Шаблон копировал общий код (вывод, ключи, `doctor`) и гейт `release.py` в каждый пакет, и `copier update` давал конфликты там, где пакет правил копию. Решили вынести его в библиотеку `rb-cli-core` (отдельный репо `bolandeu/cli-core`, реестр Gitea, semver), гейт — её командой `rb-release`; шаблон оставляет структуру и конфиги. Переход — по модулю и по пакету через вопрос copier `adopt_core`, копии удаляются из шаблона, только когда перешли все (как oslo-incubator → oslo.* в OpenStack).

Рассмотренные варианты: только настройки copier/cruft (конфликты остаются); проверяющий инструмент вместо копий без библиотеки (Scientific Python repo-review) — взят частично: гейт становится инструментом.
