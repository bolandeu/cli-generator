# Общая база инструментов: без отката на SQLite, миграции expand/contract, тесты PostgreSQL в своём контейнере

Статус: accepted (восстановлено по истории; вынесено из справочника при переходе на Стандарт, CG-044)

PostgreSQL одна на все машины, и прошлый релиз работает с ней, пока каждая машина не обновится. Поэтому: заданный, но недоступный `<TOOL>_DATABASE_URL` — ошибка `DATABASE_UNAVAILABLE`, а не тихий переход на SQLite (строки молча не попали бы в общую базу); PostgreSQL мигрирует только `db upgrade` выпущенной версии (dev-checkout не должен двигать общую базу); каждая миграция совместима с кодом прошлого релиза — сначала добавить, переключить код, удалить или переименовать старое в следующем релизе. Тесты PostgreSQL — только во временном контейнере со своим именем на порту, который выдаёт Docker: фиксированный порт однажды дал тестам одного инструмента удалить таблицу в тестовой базе другого.

Рассмотренные варианты: откат на SQLite при недоступной базе (теряет данные молча); автоматическая миграция при открытии (dev-машина двигает прод); переименование колонки одной миграцией (ломает прошлый релиз).
