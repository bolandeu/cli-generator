# Справка для человека — отдельная команда `docs`, не изменение `describe`

Статус: superseded by 0014 (2026-10-20; было: accepted 2026-10-18, IDEA-240)

`describe` — контракт для Windmill, каталога и architect; InSpectra нужна другая форма (команды в корне, примеры без пути команды, наследуются только опции). Поэтому шаблон даёт отдельную команду `docs` с кодом из semkit (`core/docs.py`), а в `describe` добавляется только безопасное поле `arity.maximum`.
