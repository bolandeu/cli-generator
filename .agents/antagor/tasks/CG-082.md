`docs/plans/simple-standard.md` — the plan behind E-006/E-007, mostly shipped; whatever it still says is undone or deferred.

Do, per file:
1. Read it whole. For each section, decide its destination: an already-shipped item (nothing), an idea (a put-off, a finding, a gap), or an ADR if it records a decision the project lives by and `docs/adr/` lacks it.
2. File the ideas with `antagor idea add`, one per item, no prefixes; the title is the item itself. Note in the report which section became which idea number.
3. Report the mapping: section -> shipped | IDEA-NNN | ADR NNNN.

Do not delete either file in this task: a plan goes only with the Human's yes on its extracted items. The epic's second acceptance (`antagor layout check` names no .md) is met by deleting the files in a follow-up after that yes; if the Human says yes inside this task, delete them and say so.

Do not implement anything the plans describe.
