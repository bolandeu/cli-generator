# Гейт — в этом репо, пакет самостоятелен

Статус: accepted (Человек, 2026-10-20; план `docs/plans/simple-standard.md`, решения 4 и 7). Заменяет 0010.

ADR 0010 выносил общий код пакетов в библиотеку `rb-cli-core` (отдельный репо, реестр Gitea). Решили иначе: пакет работает на любой машине без агента, плагина и нашей инфраструктуры, для работы — только зависимости из PyPI; слой вывода и ошибок — маленький код в самом пакете. Общим остаётся только гейт: он живёт в `gate/` этого репо, пакет запускает его через `uvx --from "git+…/cli-generator.git@<_commit>#subdirectory=gate" rb-release check`, поэтому шаблон и гейт — одна версия и `copier update` двигает обе. Репо `cli-core` и пакет `rb-cli-core` удаляются.

Рассмотренные варианты: библиотека-ядро как runtime-зависимость (0010 — пакет зависит от нашего реестра); копия `release.py` в каждом пакете (конфликты `copier update`, копии расходятся); гейт отдельным пакетом в реестре (лишний репо и релиз, версия расходится с шаблоном).
