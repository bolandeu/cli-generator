The Human's decision: local tests, CI and the runtime use one Python, 3.14. A package that promises 3.11 nobody tests is a false promise. Packages and the gate now require Python 3.14 or newer. The package CI already takes its Python from the lowest version of requires-python, so it runs on 3.14 with no new logic; only its comment changes. This repo's template-gate workflow runs on 3.14 instead of 3.12. Standard, Technology gets one Recommended line: the package requires Python 3.14 or newer, and CI and local tests run on 3.14. Existing packages get the new minimum through copier update.

## Acceptance

- Given a package rendered from the template with default answers, When its pyproject.toml is read, Then requires-python is ">=3.14" and its CI step for the lowest supported Python sets UV_PYTHON=3.14 [check: sh scripts/check_template.sh]
- Given this repo's template-gate workflow, When the test of the workflow reads its env, Then UV_PYTHON is "3.14" [check: tests/test_repo_ci.py]
- Given the gate package, When its pyproject.toml is read, Then requires-python is ">=3.14", and the gate's own tests and every rendered variant pass ruff, ty and pytest on Python 3.14 [check: sh scripts/check_template.sh]

## How to test

Integration through the template gate: the template gate script renders the minimal and the all-parts package, runs uv sync, ruff, ty, pytest and rb-release check; the repo test reads the workflow YAML. Run with Python 3.14 installed (uv picks it).

## Basis

Keep the CI step that derives UV_PYTHON from requires-python; change only the number in requires-python and the comment. Code that ruff's pyupgrade rules flag under target 3.14 is fixed in place, nothing else is reformatted. Gate test fixtures that describe a sample package keep their own requires-python.

## Read first

- `scripts/check_template.sh`
- `.gitea/workflows/template-gate.yml`

## Out of scope

Pinning a patch version (3.14.x): uv takes the newest installed 3.14. Changing installed Pythons on machines or the runner (sysadmin's). Updating existing packages (each package's copier update). A gate step that checks requires-python.
