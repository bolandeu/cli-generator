Write down the install contract agreed with sysadmin and make the cli-builder skill follow it.
Contract (architecture.md §1 'Distribution', replace the current install-channel text): a package declares [tool.rb.install] in pyproject.toml — homeserver: list of homeserver users to install for ([] = build and publish only), mac: bool (install on the Mac), extras: optional list of extras. The section present means the repo is a tool or library: sysadmin's tool-updater builds every vX.Y.Z tag, publishes the wheel to the Gitea PyPI registry (simple index https://homeserver.tailee01ab.ts.net:3000/api/packages/bolandeu/pypi/simple, anonymous read) and installs it; a Mac agent of sysadmin installs and upgrades mac = true packages. tools.toml on sysadmin's side overrides the section (pins, other users, legacy repos). The command checked is the first [project.scripts]. A library not made from this template adds the section by hand with homeserver = [] and mac = false. Installation itself is sysadmin's area; this repo only defines what the package declares.
ADR: record the decision (option B: explicit section, chosen over auto-discovery of repos because discovery would catch templates and experiments; over messaging sysadmin because the Human wants no manual step).
Skill Publish: first push to Gitea, tag v0.1.0, then once 'uv tool install --index gitea=<simple index> <dist_name>' and '<cli_name> --version' for instant use on the Mac; no message to sysadmin; no 'uv tool install .' of the checkout, no waiting for the GitHub mirror, no install check from the mirror (installability is proven by release.py --check). Scaffold step: choose the install answers (default: tool for rbtools + Mac; a library: publish only). Rename transition: no machine uninstall step; tool-updater follows the new name. Update mode: copier update brings the section; say that the gate now refuses a project without it.
AGENTS.md: add the two install questions to the list of optional generated parts.
A draft of removing the mirror-install steps exists on branch antagor/CG-022 (git show antagor/CG-022:<path>); reuse what fits.
