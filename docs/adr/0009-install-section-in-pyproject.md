# Установку пакета решает секция [tool.rb.install], а не сообщение sysadmin

Статус: accepted (2026-10-18, E-002)

Пакет объявляет в `pyproject.toml` секцию `[tool.rb.install]` (`homeserver`, `mac`, `extras`). Наличие секции значит «репо — инструмент или библиотека»: tool-updater sysadmin собирает каждый тег и ставит пакет, Mac-агент ставит `mac = true`. Контракт — в Стандарте, раздел Install. Установка — зона sysadmin, шаблон лишь объявляет.

## Рассмотренные варианты

1. Сообщение sysadmin при публикации (было) — отклонено: ручной шаг, Человек его не хочет.
2. Автообнаружение репо (B′) — отклонено: поймало бы шаблоны и эксперименты.
3. Явная секция в `pyproject.toml` (B) — выбрано.

## Последствия

- Скилл больше не пишет sysadmin и не ставит пакет из checkout или зеркала GitHub: один раз ставит с индекса Gitea на Mac.
- `tools.toml` у sysadmin переопределяет секцию (пины, другие пользователи, старые репо).
- Пакет без секции не проходит gate; библиотека не из шаблона добавляет её вручную (`homeserver = []`, `mac = false`).
