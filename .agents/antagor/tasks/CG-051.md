Packages read the Standard, and each package has its own decision records with its own numbers. The Standard's Database part sends the reader to two decision records of cli-generator by number, which mixes them up with the package's own. Drop that sentence; if a reason is still needed, give it as one 'Why:' line in the rule, like the other rules. Nothing else in the Standard changes. The repo test of the Standard checks that it names no decision record path.
