# Один Стандарт; обязательное — только то, что проверяет гейт

Статус: accepted (Человек, 2026-10-20; план `docs/plans/simple-standard.md`, решения 2, 3, 6, 9)

Требования к пакету были разнесены по трём справочникам (~1100 строк) вперемешку с историей и устройством шаблона, и многие «обязательные» правила проверяли только тесты, которые есть лишь у пакетов из шаблона. Решили: один английский `skills/cli-builder/reference/standard.md`, разделы по названию; правило **Mandatory**, только если его проверяет шаг гейта `rb-release check` (правило называет шаг), иначе **Recommended** — пакет может отойти, записав причину в своём `AGENTS.md`. Привести пакет к Стандарту = зелёный гейт, без `copier update`. Стандарт заморожен: новое правило — только если без него пакет реально ломается.

Рассмотренные варианты: оставить три файла и пометить правила (дубли и история остаются); обязательное без проверки машиной (пакет не из шаблона не проверить).
